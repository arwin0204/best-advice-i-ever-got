One sentence, up to 200 characters, on the best advice you ever received. A judge model compares them pairwise and the line that carries the most lived truth wins.

## Run it

```sh
python3 main.py /output
```

`main.py` (Python standard library only, no network, no randomness)
writes a single 153-character sentence to `<output>/entry.txt`:

> My grandmother said, 'Don't marry a man who is kind to you but cruel to the waiter,' and I have measured every person I have met since by that one table.

The output directory is the first argument, else `MAKEFUN_OUTPUT_DIR`, else `/output`. Two runs produce byte-identical output.
